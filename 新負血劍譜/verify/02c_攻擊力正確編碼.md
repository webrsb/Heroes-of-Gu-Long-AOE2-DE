# 02c — `Change Object Attack` 的 class 掃描  【P0】

**重現檔**：`ZZ_test02c_攻擊力正確編碼`　**狀態**：✅ **已完成（但 UI 數字不可信）**

## 問題

DE trigger v2.5 把攻擊力存成 `quantity = class × 65536 + amount`（v2.4 是 ×256）。
DE 轉檔把 AoC 的單純攻擊力數值在 ×256 邊界重新切分，
凡是 |值| ≥ 256 的都變成了假的 damage class。

要修，就得先確定**哪個 class 才是「單純加攻擊力」**。
本檔固定 `amount=100`，掃 class 0~6，看面板顯示。

## 結果（實機）

面板顯示 **`6+100`**（基礎 6、加成 100）。

但同一個效果（`class=0, amount=100`）在 `02b` 的**提示框**顯示
**「近戰 −94」** —— 兩個 UI 互相矛盾。

## 結論

**UI 數字不可信，兩個介面對同一份資料給出相反的數字。**

→ 改用**實際戰鬥傷害**當唯一判準，見 `02d`。
→ `02b` 依提示框寫成的「class=0 是減」結論（規則書舊 §3.3b）已作廢。

規則書：§3.3c（開頭段）
