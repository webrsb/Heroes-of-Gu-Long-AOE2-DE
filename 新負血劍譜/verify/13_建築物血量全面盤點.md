# 13 — 建築物血量灌注全面盤點

**狀態**：✅ **盤點完成（含實測補漏）** —— 需要處理的物件是 **13 個**，不是 1 個

> 初版盤點漏掉未知 const。`ZZ_test14` 實測補上 `ref 31245`（const 208，
> `亡魂之堡` 後方那座塔）—— 見 `14_未知ID是否建築.md`。

**起因**：使用者在舊版看到一棟血量 `7010000/10000` 的建築，
問「除了 `亡魂之堡` 還有其它建築物要處理的嗎」。

## 方法

`audit_buildings.py`。關鍵在於**不能只看「指名物件」的效果** ——
本體 235 個 `Change Object HP` 是用**區域 + 玩家 + 類型**指定的，
第一次只掃 `selected_object_ids` 時完全看不到它們。

解析器對每個 HP 類效果（`Change Object HP` 27 / `Damage Object` 24）
還原實際命中的物件：

```
有 selected_object_ids -> 就是那些
否則 -> 全部物件中，符合 source_player、object_list、area 三個條件者
```

## 那 11 面牆是什麼：「界線」系統

全部在地圖**上緣**（`y = 0~7`，`x = 73~91`），屬 P7，是關卡的**邊界閘門**：

```
[4421] 賓名        Change HP +9750   -> 柵欄牆 250 + 9750 = 最大血量 10000
[4447] 幫眾        Change HP +32767  條件：12 個小兵全部被消滅
[4448] 弟子        Change HP +32767  條件：6 個小兵全部被消滅
[4449] 大弟子      Change HP +32767  條件：3 個小兵全部被消滅（循環）
[4662] 觸發事件4816  Damage −200,000   條件：30808 被摧毀
[4952] 界線        Damage −100,000   條件：P1 進入 (114,0)-(114,9)
[4953~4957] 界線   Damage −70,000 ~ −160,000
```

**`250 + 9750 = 10000` —— 正是使用者截圖裡看到的那個上限。**
玩家推進到某個位置就替牆灌血、打倒一批小兵就拉高上限，
牆被打破才能前進。這是一整套關卡推進機制，不是裝飾。

## DE 會怎麼壞

與 `亡魂之堡` **完全同一個成因**（規則書 §1.2m / §5.6）：

> 建築物的當前血量被夾在最大血量；這個夾制只有在**最大血量 = 0** 時才失效。

| | 舊版 1.21z | DE |
|---|---|---|
| 最大血量 | 10000 | 10000 |
| 灌血後當前血量 | **836,086** | **夾成 10000** |
| 承受正傷害 | 80,000 → 撐得住 | 80,000 → **瞬間破** |

→ **邊界牆會比設計早破**，玩家可以提前穿越關卡邊界，
　小兵還沒打完就跨區，後續觸發器的前提全部失效。

嚴重度與 `亡魂之堡` 同級，只是表現形式不同：
一個是魔王秒殺，一個是關卡結構崩掉。

## 修法

**與 `亡魂之堡` 同一套：雙 0 血。**

```
ADD(65536 − 當前最大血量)  ->  最大血量 = 0（關掉夾制）
再施加負傷害                ->  當前血量灌到百萬級
```

12 個物件都適用，不需要為牆另外設計。差別只在：

- `亡魂之堡` 需要**血條**（雙 0 血後建築顯示 `❤ 0`，玩家看不到進度）
- 11 面牆**不需要血條** —— 它們是邊界，玩家不需要看到剩餘量

## 不受影響的部分

- **其餘 77 面柵欄牆**：只吃 `Change HP` 與正傷害，**沒有灌血**，
  當前血量從未超過上限 → 夾制咬不到它們
- **單位**：DE 不夾單位的當前血量（`ZZ_test01` 系列已實測），
  120 個受影響的單位全部安全
- 橋樑（`BRIDGE_*` ×5）、農田、石牆、鐵匠鋪、大學：只有 `ΔmaxHP` 或小額正傷害

## 殘留疑點：柵欄牆的 int16 溢位

11 面牆的 `ΔmaxHP` 合計是 **+42517**（`+9750` 與 `+32767`），
加上底值 250 得 **42767**，**超過 int16 上限 32767**
→ 會回繞成 **−22769**。

但這在舊版是同樣的行為（`Change Object HP` 的最大血量欄位在兩版都是 int16），
**不是 DE 迴歸**，而是作者原有的溢位，與 `南宮尾葉` 同類。
且 `賓名` 與 `幫眾/弟子/大弟子` 是否對同一面牆都成立，需實機確認
（條件是不同批小兵被消滅，可能互斥）。

**採用雙 0 血修法後這個疑點自動消失** —— 最大血量會被明確設成 0。

規則書：§5.7
