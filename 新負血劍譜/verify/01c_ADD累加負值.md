## 已知前提（前兩輪實測確立，等級 A）

1. `operation = -1` **等同 ADD（相加）** — 本體 790 個效果全用此值
2. 用 **SET** 把最大血量設成回繞負值 → **DE 殺死單位**
3. `Change Object HP` 會做 **mod 65536 回繞**
4. **Man-at-Arms 基礎血量 = 45**（實測確認，本檔的計算基準）
5. AoC 同樣是 ADD（由 nakuz Q61「雙0血」與 Q68「還原」步驟反證）

## 唯一未解的問題

**SET 產生的負值會致命。那 ADD 累加使「基礎血量 + 增量」落到 0 或負值，是否同樣致命？**

這決定本體 `馬血` 那六隻坐騎（增量 +17 ~ −250）以及整個「負血 / 雙0血」設計在 DE 能不能用。

## 結論

**ADD 累加到 0 或負值，單位會死亡。**

C2（只把最大血量變 0、不灌血）也死亡 —— 這一點後來很重要：
`01n` 一開始就是因為這裡的 C2 結果，誤判「雙0血不可行」，
實際上 C2 只做了 `NAKUZ` Q61 的**第一步**，漏掉後面的灌血兩步。

死亡判定看的是**當前血量 ≤ 0**：`Change Object HP` 等比縮放當前血量，
最大血量變負 → 當前血量也跟著變負 → 死亡。

但這**不代表負最大血量本身致命**：若**先翻負、後灌血**，
當前血量會被推回正值而存活（見 `01e` E5，提示框顯示 `−205` 但活著）。

規則書：§0.2、§1.2c
