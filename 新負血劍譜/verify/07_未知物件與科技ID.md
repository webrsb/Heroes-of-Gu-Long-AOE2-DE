| ID | 用途 | 出現次數 |
|---|---|---|

### 待辦修改（**未套用**，等使用者指示）

```

      unit_const   436  ->  2353
```

## 測試設計上的兩個教訓

### `-1` 是「未設定」哨兵值（只在 `Tribute`）

`ZZ_test07e` 用 `Tribute -1` 當計數器，石頭停在 0。
詳見 `11_負1哨兵值.md`：`Tribute -1` 不執行，`Damage -1` 正常。

### `Own Fewer Objects` 是「擁有數 ≤ N」不是「< N」

`ZZ_test07e` 用 `quantity = 1`，於是「正好擁有 1 個」也算成立，
**45 個 ID 全部誤報 `[無效]`**。

本體用它時填 `quantity = 0`（`飛鵬幫先鋒`、`飛鵬幫戰將`），
若語意是「小於 0」則永遠不成立 —— 可見必為「≤ N」。
`ZZ_test07g` 改用 `quantity = 0` 後結果才正確。

**每個測試都必須有陽性對照。** 07e 缺了它，才會把自己的 bug
誤讀成「45 個 ID 全滅」。
