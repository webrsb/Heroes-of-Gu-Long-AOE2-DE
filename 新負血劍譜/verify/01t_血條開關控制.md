# 01t — 血條只在最終戰期間顯示  【已被 01u 涵蓋】

**重現檔**：`ZZ_test01t_血條開關控制`　**狀態**：⚠️ **內容已被 `01u` 完整涵蓋**

## 問題

血條的條件是**永不成立**（否則會被劃刪除線），所以它一旦啟用就**掛到遊戲結束**。
亡魂之堡是最終戰，開場第一秒就顯示「亡魂之堡 100％」是錯的。

| # | 問題 |
|---|---|
| Q1 | `enabled = 0` 的觸發器，其目標文字是否不顯示？ |
| Q2 | `Activate Trigger` 之後才顯示？ |
| Q3 | `Deactivate Trigger` 之後是否收掉？ |

## 設計

```
 0 秒  血條停用中   -> 右上角應空白
 8 秒  Activate     -> 出現「亡魂之堡 100％」
擊殺後 Deactivate   -> 消失
```

階梯觸發器也初始 `enabled=0`，一併 Activate，
最終戰之前省下 100 個觸發器的每 tick 條件檢查。

## 為何併入 01u

`01u` 在此之上再加**距離控制**（離開附近也要消失），
血條的顯示完全交給距離開關決定，因此 `01u` **包含 `01t` 的全部內容**。
使用者實測 `01u` 通過，本檔不需單獨執行。
