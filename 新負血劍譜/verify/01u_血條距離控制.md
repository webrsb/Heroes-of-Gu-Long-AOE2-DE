# 01u — 血條隨距離出現／消失  【P1】

**重現檔**：`ZZ_test01u_血條距離控制`　**狀態**：✅ **已完成（使用者確認通過）**

## 問題

使用者需求：不只「最終戰期間」，**離開亡魂之堡附近血條也要消失**。

AoE2 沒有鏡頭位置條件，只能用**單位距離**判定 —— 語意上也正確：
自己的角色在打魔王 → 血條在；角色撤退或全滅 → 血條收掉。

## 設計

血條本身仍是 `enabled=0` + 永不成立條件（避免刪除線），
顯示與否完全交給兩個**循環**觸發器：

| 觸發器 | 條件 | 效果 |
|---|---|---|
| 顯示控制（循環） | `objects_in_area(近框 ±12, quantity≥1, source_player=1)` | `Activate` 血條 |
| 隱藏控制（循環） | `objects_in_area(遠框 ±16, quantity≥1, **inverted=1**)` | `Deactivate` 血條 |

**API 事實**：`objects_in_area` **沒有 `comparison` 參數**，
反向判定靠 `inverted=1`（語意為「區域內少於 quantity 個」）。

同檔放兩條血條，因為「附近」的判定對象有兩種語意：
- **A**（`object_list=-1`，任何 P1 物件）—— 正式版採用。攻擊者貼著城堡打 → 持續顯示
- **B**（`object_list=83`，只看村民）—— 供手動走進／走出驗證開關真的有效

## 結果

使用者實測通過。

## 兩個必須記下的實作細節

**🔴 必須設緩衝區**：近框 ±12、遠框 ±16。

```
        ±12 ────────────────┐  進入 → 顯示
    ±16 ──────────────────────┐  離開 → 隱藏
        │  12~16 之間：兩個條件都不成立 → 維持現狀
```

兩框同大小的話，玩家站在邊界上血條會**每秒閃爍一次**。

**🔴 收尾順序**：魔王死亡時要**先 Deactivate 距離開關，再 Deactivate 血條**。
反過來的話血條會在下一個 tick 被還在跑的顯示控制重新打開。

## 附帶：階梯的自我校正性質

階梯依百分比**遞減**建立，故 trigger id 遞增 = 百分比遞減。
一個 tick 內若有多個門檻同時成立，**最後執行的正好是最低的成立門檻** —— 就是正確值。

→ 階梯即使中途停用再啟用，也不會顯示錯誤數字。
→ 所以階梯可以全程保持啟用（讓變數隨時是最新值），不必隨距離開關。

規則書：§5.6d-3
