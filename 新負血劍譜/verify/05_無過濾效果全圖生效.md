# 05 — 無過濾效果是否真的全地圖生效  【P2】

**狀態**：✅ **已測・仍全圖生效** —— 18 處不必改（`ZZ_test05b`）

**重現檔**：`ZZ_test05b_無過濾效果`　**耗時**：約 45 秒

> 舊版 `ZZ_test05` 已作廢：它把無過濾效果打在 **P1（人類玩家）**身上，
> P1 全滅會直接判定落敗、劇情中斷，回報根本來不及顯示。

## 問題

UGC 指南對幾乎每個帶區域的效果都寫著：
> *"Area … When not set, units across the entire map have their HP changed"*

本體有 **18 個破壞性效果**（原記錄 22 有誤，2026-08-29 重新盤點）完全沒有過濾（無選取單位、無區域、無單位類型、無類別），只設了 Source Player。若指南所述為真，這些是全地圖生效。

最危險的一組是 `[4945]～[4950] 修端慕草1-6`：

```
條件: Capture Object (P1~P6 擷取 ref 37096 = King Alfonso @ 200.5,4.5)
      Destroy Object (同一個 ref 37096)
效果: Remove Object，source_player = 1~6，完全無過濾
```

且這 6 個觸發器都是 **enabled + looping**。若兩個條件同時成立，該玩家的**所有單位**會每秒被移除一次。

> 補充：條件是「擷取」且「摧毀」同一個單位——先被擷取、之後被摧毀是有可能依序成立的，
> 所以不能斷定它永不觸發。

其他 16 個無過濾效果分佈在 `[4003] 1鮮2`、`[4958]～[4963]`（黃金 ≥ 300000 時每 3 秒全圖 200 傷害，疑似刻意的防作弊）、`[5230] 修1`。

## 測試檔內容

- P1：1 隻村民 + 5 隻近端步兵（近端1～5）+ 1 隻遠端步兵（放在 40,40）
- P2：1 隻步兵（對照組，不該被影響）
- 5 秒後執行一個 `Remove Object`，`source_player = 1`，**完全不加任何過濾**

## 怎麼看

看 5 秒後 P1 還剩幾個單位，以及聊天欄的移除回報。

## 判讀

| 觀察 | 結論 | 後續 |
|---|---|---|
| P1 全部消失（含遠端 40,40 與村民），P2 留著 | ✅ 確認全圖生效 | 🔴 本體 22 處需逐個判斷是否刻意，`修端慕草` 尤其危險 |
| 只有近端 5 隻消失，遠端留著 | 有隱含範圍限制 | 風險降低，記錄範圍行為 |
| 完全沒有單位消失 | 無過濾效果是空操作 | ✅ 本體 22 處都是死碼，不用管 |
| P2 也消失 | Source Player 也沒作用 | 更嚴重，需記錄 |
| 遊戲直接判定落敗 | P1 全滅 → 即為「全圖生效」的證據 | 同第一列 |

## 後續判斷方式（若確認全圖生效）

那 22 個效果要分成兩類：
- **刻意的**：`[4958]～[4963]` 看起來是防作弊（黃金太多就懲罰），全圖生效合理，保留
- **疑似遺漏**：`修端慕草1-6` 的 `Remove Object` 全圖刪單位，很可能作者原意是刪特定單位
  但注意：本體的 3660 個單位參照**零失效**，所以空選取是原始檔案本來就這樣，不是轉檔遺失

## 結果

**2026-08-29 實測（`ZZ_test05b`，80×80 地圖，近端 (12,y) 與遠端 (70,y) 相隔 58 格）。**

```
[結果] P4 傷害+200      近端 消失了    遠端 消失了
[結果] P5 回血-300      遠端 血量 > 40 近端 血量 > 40
[結果] P6 修1回繞值      近端 消失了    遠端 消失了   房屋 消失了
[結果] P3 全圖 REMOVE   近端 消失了    遠端 消失了   房屋 消失了
```

**沒有出現任何 `[異常] P2 對照 … 竟然也消失`** —— 效果不會外溢到其他玩家，
測試前提成立。

| 效果 | 近端 | 遠端（58 格外） | 房屋 |
|---|---|---|---|
| `Damage Object` +200 | ✅ 死 | ✅ 死 | 存活（正常：200 < 房屋血量） |
| `Damage Object` −300（回血） | ✅ 生效 | ✅ 生效 | — |
| `Damage Object` 1294967296 | ✅ 死 | ✅ 死 | ✅ 死 |
| `Remove Object` | ✅ 消失 | ✅ 消失 | ✅ 消失 |

### 結論

**DE 仍然讓無過濾的破壞性效果全地圖生效。**
`source_player` 之外不加任何條件時，該玩家**全部**物件都吃到，
與距離無關、與物件類型無關，且**不跨玩家**。

→ 本體 **18 個無過濾破壞型效果不必改**。
　作者刻意依賴全圖生效的寫法（`修端慕草` 清場、群體傷害、全圖回血）可原樣遷移。

### 附帶確認：`[5230] 修1` 的回繞值是「正數傷害」

`1294967296` 施加後**近端、遠端、房屋全部消失**。

證實 `修1` 的語意錯誤：作者用 `4294967296 − N` 想寫「回血 30 億」，
但 N = 3,000,000,000 超過 int32 下限，公式靜默失效成 **+12.9 億傷害**。
**意圖治療，實際團滅** —— 連建築物都秒殺。

嚴重度仍維持**低**：該觸發器的條件是 `PLAYER_DEFEATED sp = 1`，
只在玩家已經落敗後才執行，打不到還在遊玩的玩家。
