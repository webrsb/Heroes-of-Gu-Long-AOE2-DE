## 待解問題

`Change Object HP` 寫的是**最大血量（int16）**，天花板 **32767**。
城堡基礎 4800，最多只能墊到 32767 —— 與原本 6,000,000 差 **183 倍**。

**有沒有辦法突破天花板？**

## 測試檔內容

7 個物件排成一列（y=18）。因為 `Modify Attribute` 是按「**單位類型 + 玩家**」作用而非指定單位，
所以每條 lane 放在不同玩家避免互相污染。P1~P6 已設為同盟，可互相看到血量。

| lane | 玩家 | 做法 | 門檻 | 目的 |
|---|---|---|---|---|
| `G1 ModAttr HP +600萬` | P1 | `Modify Attribute` 屬性 0 `HIT_POINTS` **+6,000,000** | >100,000 | **本體真實需求** |
| `G2 ModAttr HP +30000` | P2 | 同上 **+30,000** | >20,000 | 小額，看是否回繞 |
| `G3 ModAttr 無敵等級 −600萬` | P3 | `Modify Attribute` 屬性 129 `INVULNERABILITY_LEVEL` **−6,000,000** | >4,000 | `UGC`：負值 = 固定血量模式 |
| `G4 ChangeHP +27967` | P4 | `Change Object HP` +27,967 | >30,000 | 剛好到 32767 天花板 |
| `G5 ChangeHP +30000` | P5 | `Change Object HP` +30,000（4800+30000=34800 超標） | >30,000 | 看是回繞還是死亡 |

## 怎麼看

等 15 秒，然後**逐一點選 7 個物件**，記下名稱有無 `>>>生效<<<` 以及血量數字。
**G3 請額外用步兵攻擊它幾下**，看血量會不會掉。

## 結論

1. **`Modify Attribute HIT_POINTS` 這條路封閉** —— 對已存在的建築物不生效。
2. **`Change Object HP` 的硬上限就是 32767**，超過一點就回繞致死。
   → 規則統一：**最大血量因回繞 ≤ 0 時，單位與建築物都會死**
   　（早期誤判建築物較寬容，已修正）。
3. **`1045/45` 是兩欄位模型的直接目視證據**，顯示格式為「當前 / 最大」。

當時的結論是「`亡魂之堡` 有效血量上限就是 32767，缺口 183 倍」。

## 後續：這個結論已被推翻

`01j` 證實 `INVULNERABILITY_LEVEL`（G3 那條）用正確語意重測也全部失敗；
但 `01n` 找到真正的出路 —— **雙0血**：最大血量設為 0 時建築物的夾限不生效，
可持有 600 萬當前血量。缺口 183 倍的問題**根本不存在**。
