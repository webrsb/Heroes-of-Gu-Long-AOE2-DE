# 01h — `Change Object HP` 對當前血量做什麼  【P0】

**重現檔**：`ZZ_test01h_ChangeHP是否覆寫當前血量`　**狀態**：✅ **已完成**

## 問題

已知 `Change Object HP` 會改最大血量。但它對**當前血量**做什麼？
三種可能：不動、覆寫成新的最大值、或等比例縮放。

這決定了「爆血」機制（當前血量遠超最大血量）能不能成立，
也決定 `亡魂之堡` 的修法方向。

## 測試設計

用**順序**當變數：治療與 `Change Object HP` 誰先誰後，結果會不同才能分辨模型。

## 結果（實機）

| lane | 序列 | 實測血量 | 模型計算 | 一致 |
|---|---|---|---|---|
| H2 | 治療 100000 | `100045/45` | 45 + 100000 | ✅ |
| H3 | ChangeHP+100 → 治療 | `100145/145` | 145 + 100000 | ✅ |
| **H1** | 治療 → ChangeHP+100 | **`322367/145`** | 100045 × 145/45 = 322367.2 | ✅ |
| H4 | 治療 → ChangeHP+10000 | `…332266/10045` | 100045 × 10045/45 = 22332267 | ✅ |
| H5 | 治療 155,204,605（Archbishop） | **`155204672/70`** | — | ✅ |
| H6 | 基準 Archbishop | `70/70` | 基礎血量 70 | ✅ |

## 結論

```
Change Object HP（相加 n）：
    新最大血量 = int16(舊最大血量 + n)                  ← 會 mod 65536 回繞
    新當前血量 = 舊當前血量 × 新最大血量 ÷ 舊最大血量     ← **等比例縮放**

Damage Object（負值 n）：
    新當前血量 = 舊當前血量 + |n|                       ← 不回繞、無上限

死亡判定：只看「當前血量 ≤ 0」，不看最大血量
```

**關鍵：`Change Object HP` 不是覆寫當前血量，而是等比例縮放（維持血量百分比）。**

H5 的 `155204672/70` 與本體 `毀僧聖僧` 在舊版與 DE 的顯示**位元級相同**，
這是「爆血」機制跨版本一致的直接證據。
