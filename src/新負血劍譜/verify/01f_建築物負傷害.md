## 若 bug 仍在 — 修法

亡魂之堡需要 600 萬血，但 `Change Object HP` 的最大血量上限是 **32767**，塞不下。可行方向：

1. **改用 `Change Object HP` 墊到接近上限**（例如 30000），接受耐久度從 600 萬降到 3 萬
2. **把該物件換成非建築單位**（會改變外觀與行為，影響較大）
3. **改用 `Modify Attribute` 屬性 129 `Invulnerability Level`**（負值 = 固定血量模式），
   若對建築物有效，可完全取代
4. **接受它可被摧毀**，並檢查有沒有觸發器依賴它存活

F6 就是在測方向 1 是否可行。

## 當時的結論（後被推翻）

> 「建築物完全不吃 `Damage Object` 負值。」

## 為何錯 —— `01i` 的修正

**測試設計有缺陷：本檔的城堡是滿血狀態（4800/4800），補不上去，
所以看不出效果，被誤讀成「沒生效」。**

`01i` 先把城堡扣掉 1000 血（3800/4800）再施加，結果是 **4800/4800** ——
**負傷害有生效，只是被夾在最大值**。

真正的規則：

```
單位   ：當前血量可以遠超最大血量      （1045/45）
建築物 ：當前血量被夾在最大血量以內    （怎麼灌都只到 4800/4800）
```

**F5 的 `1045/45` 仍是有效收穫** —— 它是「當前 / 最大」兩欄位模型的
直接目視證據，也是 `operation = -1` 為 ADD 的佐證之一。

規則書：§1.2k（修正）、§1.2j
