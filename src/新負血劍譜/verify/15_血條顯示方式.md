# 15 — 血條的顯示方式：改用 `Change Object Caption`

**狀態**：✅ **已測・改採 caption** —— 完全不進任務面板，設計比原方案更簡單

## 起因

使用者問：畫面上那條字能不能**不要頂著「任務」標題**。
原血條設計走觸發器顯示旗標（`display_on_screen=1` / `display_as_objective=0`），
落在任務面板裡。

## 四種寫法比較（`ZZ_test15`）

| | 寫法 | 結果 |
|---|---|---|
| A | `display_on_screen=1` + `display_as_objective=0` | 任務面板 |
| B | `display_as_objective=1` | 任務面板（對照） |
| C1/C2 | `Display Instructions` 面板位置 0 / 2 | 訊息面板 |
| **D** | **`Change Object Caption`（效果 88）** | **字浮在物件上方，完全不碰任務面板** |

**使用者選定 D。**

## Caption 的四個性質（`ZZ_test15b`）

五座哨塔並排，逐項驗證：

| 項 | 內容 | 結果 |
|---|---|---|
| **A** | 半形 `%` | ✅ `亡魂之堡 87%` 完整顯示 |
| **B** | 全形 `％`（U+FF05） | ❌ 豆腐格 —— **caption 字型沒有這個字** |
| **C** | `血量 <測試百分比>%` | ❌ **不代入變數**，原字照印 |
| **D** | 連續更新 100% → 63% → 12% | ✅ 即時更新，哨塔與城堡行為一致 |
| **E** | `▮▯ ■□ ●○ ★ ❤ ▁▃▅` | ❌ **全部變問號** |

**最關鍵的一點：五座塔全程未被選取，字照樣浮在上方。**
caption 可以當常駐 HUD 用，不需要玩家點選。

### 兩條顯示途徑的字型不同

任務面板的字型**有**全形 `％`（`ZZ_test01s` 的 `<魔王百分比>％` 顯示正常），
caption 的字型**沒有**。方塊、圓點、星號、愛心、區塊字元在 caption 全部陣亡。

→ **caption 只能用 ASCII 與中日韓文字。**

## 對血條設計的影響

| 原設計（任務面板） | 新設計（caption） |
|---|---|
| 2 個顯示觸發器 + 永不成立條件 | **0 個** |
| 距離開關 2 個 + 遲滯 ±12/±16 | **0 個** —— 看不到魔王時本來就看不到字 |
| 清除觸發器 2 個 | 0 個（物件死了字跟著消失） |
| 佔用畫面右上角、頂著「任務」標題 | 不碰任務面板，F4 完全乾淨 |
| 支援 `<變數名>`，1 個顯示 + 100 個改變數 | **不支援變數 -> 100 個階梯各送一次固定文字** |

**觸發器數量從約 206 降到 200**，而且結構單純得多：
每個階梯觸發器 = 1 個 `Object HP <` 條件 + 1 個 `Change Object Caption` 效果。

距離控制、遲滯、開關、清除**整套都不需要了** ——
caption 綁在物件上，玩家看得到魔王才看得到字。

## 圖形化血條仍然可行（改用 ASCII）

區塊字元全掛，但 ASCII 一定能顯示：

```
亡魂之堡 [####------] 40%
聚魂塔   [########--] 80%
```

10 格 = 每格 10%，比純數字直觀。

### 樣式選型（`ZZ_test15c`）—— 使用者選定 **樣式 3**

八種並排比較，全部顯示 40%：

```
1  [####------]    2  [====------]    3  [####______]  <- 選定
4  [||||......]    5  田田田田口口口口口口   6  回回回回口口口口口口
7  一一一一　　　　　　  8  純數字（對照）
```

**定案格式**：

```
亡魂之堡 [####______] 40%
聚魂塔 [########__] 80%
```

填滿 `#`、空白 `_`、方括號包住、10 格 = 每格 10%，數字接在後面。
中日韓樣式（5/6/7）雖然一定等寬，但佔的橫向空間是 ASCII 的兩倍，未採用。

規則書：§5.7a
