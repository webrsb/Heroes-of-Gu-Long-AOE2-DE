# 02e — 負值攻擊力（解除加成）的正確寫法  【P0・定論】

**重現檔**：`ZZ_test02e_負值攻擊力寫法`　**狀態**：✅ **已完成**

## 問題

本體的攻擊力加成是**成對**的：買神兵時 `+N`、失效時 `−N`。
`02d` 定了正值的修法，負值那 134 個要怎麼寫？

三種候選：`operation=SUBTRACT` 搭正的 amount、`ADD` 搭負的 amount、
或直接沿用本體的 raw 負值。

測法同 `02d`：靶最大血量 20045、凍結不反擊、攻擊者原地防守、約 7 下。

## 結果（實機）

| lane | 序列 | 剩餘血量 | 傷害 | 攻擊力 |
|---|---|---|---|---|
| F1 | 未加成（基準） | 20003 | 42 | 6 |
| F2 | `class0 +500 ADD`（校準） | 16503 | 3542 | 506 |
| **F3** | `+500 ADD` → **`500 SUBTRACT`** | **20003**（＝F1） | 42 | **6** ✅ |
| F4 | `+500 ADD` → `200 SUBTRACT` | 17903 | 2142 | 306 ✅ |
| **F5** | `+500 ADD` → `ADD(−500)` | **16503**（＝F2） | 3542 | 506 🔴 |
| **F6** | `+500 ADD` → **raw −65652** | **16503**（＝F2） | 3542 | 506 🔴 |

## 結論

1. **`operation=SUBTRACT` 搭配正的 amount 是正解。**
   F3 精確回到基準、F4 精確落在 306。
2. **`ADD` 搭負值無效**（F5 沒有任何變化）。
3. **本體 134 個負值效果完全無作用。** F6 是 `1刀52`（raw −65652）的位元組重現，
   加成一點都沒被解除。
4. → DE 中**加成與解除加成兩邊都失效**，攻擊力系統整體是平的。
   **這正是神兵問題的成因**：付出每秒 6000 扣血的代價，攻擊力卻不變。

## 最終修復規則

```python
def restore(de_raw):
    sign = -1 if de_raw < 0 else 1
    v = abs(de_raw)
    V = (v >> 16) * 256 + (v & 0xFFFF)      # 還原 AoC 原值
    return (V, ADD) if sign > 0 else (V, SUBTRACT)
```

| 類別 | 數量 | 處理 |
|---|---|---|
| DE class = 0（原值 < 256） | 487 | ✅ 不動 |
| DE class ≥ 1（原值 ≥ 256） | 299 | 🔴 改寫為 `class=0, amount=V, ADD` |
| DE class < 0（原值為負） | 174 | 🔴 改寫為 `class=0, amount=V, SUBTRACT` |

驗算 `1刀52`：`−65652` → `1 × 256 + 116 = 372` → `class=0, amount=372, SUBTRACT` ✅
（其配對 `1刀5` = `+65652` → `ADD`，加成與解除正確成對）
