# 02d — 以實際傷害量測攻擊力編碼  【P0・定論】

**重現檔**：`ZZ_test02d_攻擊力實際傷害`　**狀態**：✅ **已完成 —— 這是修復依據**

## 為何改用傷害量測

`02b` 的提示框說「近戰 −94」、`02c` 的面板說「6+100」，同一份資料兩個相反答案。
UI 不可信，只有**實際造成的傷害**是事實。

測法：靶最大血量 2045、已凍結不反擊、攻擊者原地防守、打約 7 下，量剩餘血量。

## 結果（實機）

| lane | 編碼 | 剩餘血量 | 造成傷害 | 推得攻擊力 |
|---|---|---|---|---|
| E1 基準 | 未加成 | 2003 | 42 | **6** |
| **E2** | **class=0, amount=100** | **1303** | **742** | **106** ✅ |
| **E3** | class=4, amount=100 | **1303** | **742** | **106** ✅ 與 class 0 相同 |
| **E4** | **class=78, amount=32** | **2003** | **42** | **6** 🔴 **完全無加成** |
| E5 | class=4, amount=30000 | 靶死亡 | — | 極高 ✅ |
| E6 | class=0, amount=30000 | 靶死亡 | — | 極高 ✅ |

## 結論

1. **`class=0, amount=N` 就是「攻擊力 +N」。** E2 與 E3 傷害完全相同
   → 提示框的 `−94` 是**顯示假象**。
2. **本體那 487 個 class=0 的效果本來就是好的**，不需修改。
3. **`class=78, amount=32` 完全無加成**（E4 傷害與基準一致）。
   該打包值 `5111840` 與本體 `火砲2` / `2刀3` / `周賓???` **位元組完全相同**
   → **確認 473 個效果在 DE 是死的。**
4. **沒有 255 上限**：class=0 帶 30000 一擊秒殺 2045 血的靶。
   `UGC` 指南的「quantity 上限 255」與實測不符。

## 修法（正值）

```
V = (DE現值 >> 16) × 256 + (DE現值 & 0xFFFF)      # 還原 AoC 原值
-> change_object_attack(armour_attack_class=0, armour_attack_quantity=V, operation=ADD)
```

驗算 `火砲2`：`5111840` → `78 × 256 + 32 = 20000` → `class=0, amount=20000` ✅
