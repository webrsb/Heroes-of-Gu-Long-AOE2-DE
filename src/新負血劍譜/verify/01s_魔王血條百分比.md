# 01s — 魔王血條第二版：百分比 + 不進任務清單  【P1】

**重現檔**：`ZZ_test01s_魔王血條百分比`　**狀態**：✅ **已完成**

## 改了什麼

**① 改用百分比**（`01r` 的原始血量會斷行）
1% = 60,000，共 100 個階梯 —— 比 `01r` 的 30,000 間距**少一半觸發器**，
而且每兩下更新一格，粒度足夠。

**② 不進 F4 任務清單**
使用者裁定：本體有自己的任務文字，血條塞進清單會**擾亂原本的任務呈現**，
而且沒人會點進去看。

| 欄位 | 值 | 理由 |
|---|---|---|
| `display_on_screen` | 1 | 右上角長駐 |
| `display_as_objective` | **0** | 不進 F4 清單 |
| `description` | `""` | 同上 |
| `description_order` | 99 | 排在本體任務下方 |
| `mute_objectives` | 1 | 每 1% 更新，避免提示音／閃爍 |

為了判斷右上角是靠哪個旗標顯示，同檔放了一個 `display_as_objective=1` 的對照組。

## 結果（實機）

**右上角兩行都出現**：`亡魂之堡 97％` 與 `[對照] 亡魂之堡 97％`
→ **`display_on_screen=1` 搭配 `display_as_objective=0` 仍然顯示** ✅

**F4 任務清單只有 `[對照]` 那行** → 不進清單的版本確實不污染任務呈現 ✅

**排版正常**，無斷行、無刪除線 ✅

## 附帶確認的一件事

雙0血狀態下**建築物自己看不到血量進度**：
滑鼠提示顯示 `❤ 0`，選取面板也沒有遞減數字。

這和舊版 `6000300/300`（玩家看得到數字往下跑）**不一樣**，是真實的體驗落差。
→ **右上角血條不是加分項，是補回舊版原有資訊的必要元件。**
→ 本體那 100 個階梯觸發器省不掉。

## 另一項確認

**本體 5232 個觸發器的顯示旗標全為 0 個**
（`display_on_screen` 與 `display_as_objective` 都沒人用，作者全靠聊天訊息與提示面板敘事）。

→ 加入血條後 F4 清單維持全空（與原版一致），右上角只有血條那一行，**零干擾**。
