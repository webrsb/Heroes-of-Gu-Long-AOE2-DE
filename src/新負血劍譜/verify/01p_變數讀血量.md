# 01p — 能不能把建築物的當前血量讀進變數  【P0】

**重現檔**：`ZZ_test01p_變數讀血量`　**狀態**：✅ **已完成（結論：不能）**

## 問題

做血條需要一個「數字」。DE 新增了變數系統，看起來有現成的路：

```
MODIFY_VARIABLE_BY_ATTRIBUTE (87)   變數 := 物件屬性（屬性 0 = HIT_POINTS）
MODIFY_RESOURCE_BY_VARIABLE  (53)   資源 := 變數（倒進資源就能顯示在畫面上方）
VARIABLE_VALUE               (22)   條件，比對變數
```

讀數方式：P1 的「石頭」= 城堡當前血量（每秒更新），「木材」= 循環次數。

## 結果（實機・使用者回報）

**石頭一直是 4800，不會變。**（木材正常累加，證明循環有在跑）

4800 正好是**城堡型別的基礎血量**，不是那座城堡的當前血量。

## 結論

**`Modify Variable By Attribute` 是「型別層級」查詢**
（參數只有 `object_list_unit_id` + `source_player`，沒有 `unit_object`），
讀到的是**單位型別的屬性值**，不是某個實例的當前血量。

**DE 沒有「把實例當前血量讀進變數」的效果。**

→ 數字血條不能走這條路。
→ 改用 `Object HP` **條件**（它吃 `unit_object`，是實例層級）
　 搭配門檻階梯反推血量，見 `01q` / `01s`。

規則書：§5.6b
