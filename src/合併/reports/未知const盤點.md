# 無法無天新內容・灌血物件全面盤點（工項 3，2026-08-29 收案）

## 方法

對 origin 基底全量解析（效果目標三模式），列出所有被灌血（負 Damage）的物件，
排除已處理的 13 個雙0血目標，按 const 用 parser 資料集分類。

| 類別 | consts | 判定 |

| 特殊物件 | 66 金礦(−2億)、602 旗幟C、688 聖物碎片×4(−99萬)、738 裂橋 | **無任何觸發以其存亡為條件**（全檔掃描確認）；灌血是「拆不掉保險」，夾掉頂多失去保險，無劇情影響 → **接受** |

  單位在 DE 本來就不夾血，虛驚一場。
