# 古龍921 合併版（無法無天基底）破關攻略

依據 `src/合併/out/古龍921_合併.aoe2scenario` 全部 5,799 個觸發、10,709 個單位的逐條解析寫成。
網路上流傳的 nakuz／PTT 攻略（見 `攻略.txt`）寫的是舊版《新負血劍譜》，本合併版以「無法無天」
為基底，是一次系統性改版：任務結構大致相同，但**回血任務全部重寫、新增毀滅之魂／破壞武神／
神兵系統、最終戰加上時間壓力**。以下所有座標、數值皆出自檔案實測解析，格式為 (x, y)，地圖 240×240，
(0,0) 在最上角（北），x 向右、y 向下。

## 一、破關條件（檔案定案）

> **摧毀左上角「聚魂塔」（0,4）與「亡魂之堡」城堡（4,5）→ 10 秒後全體玩家宣告勝利。**

- 觸發鏈：`嬴`（兩者皆毀）→ `嬴2`（10 秒延遲 → declare victory ×7）。
- 聚魂塔血池 **1,895,504**、亡魂之堡血池 **6,000,780**（合併版有即時血條，開局 20 秒後顯示）。
- 殺死賓周**不是**勝利條件，但是必經之路（開最後的門、召來幫手）。

## 二、基本系統

| 遊戲概念 | 引擎資源 | 取得方式 |
|---|---|---|
| 江湖閱歷（經驗值） | 石頭 | 怪物「最後一擊」由你的單位補刀 |
| 銀兩 | 黃金 | 補刀、任務 |
| 珍貴木材（技能點） | 木材 | 在森林區補刀（每殺 +2）、任務 |
| 靈島鳳仙肉 | 食物 | 在靈島（漢娜斯一帶）補刀（每殺 +100） |

- **等級＝累積經驗門檻**：16 等＝1,160、30 等＝6,235、50 等＝25,725、60 等＝43,070、
  **約 70 等＝66,815（最終戰入場門檻）**、100 等＝186,125。51 等起「刀客」改名「刀俠」。
- **道具＝地圖最下緣 y=239 一排的隱形標記物**，每格一種道具（例：216=惡夢首級成果、
  219=象皮甲、220=任督圖、223=九天玄壁、229=推薦書）。迪加、第10層武學等都是「數這排有幾件」。
- **精力＝生命值**。任務獎勵分兩種：「精力上限 +N」（改最大血）與「灌血 −N 傷害」（直接超灌現血，
  可以超過上限，本專案已在 DE 實測有效）。回血術是每秒灌血的迴圈，**越早拿、之後升級血量翻倍越兇**
  ——舊攻略的「倍數」策略仍然成立。
- 單人遊玩：**必須玩 1P 刀客**（檔內語音提示明言「刀客棄權其他玩家會跳開遊戲」；勝利鏈也以 P1 任務線為主幹）。
  P2–P6 的職業專屬任務（金獅劍、銀龍爪、慕容鋼槍、如意棒、冷月護甲）單人時可忽略。

## 五、任務攻略（建議順序）

### 開局第一小時（衝倍數）

1. **刀客回血術——第一優先**：直接走到**刀駝 (39,35)**（香城西北）身邊
   → 永久 **+28 血/秒**（上馬後 +21/秒）。這是全場最重要的一步，上限還很低時拿到，
   之後每次升級血量按比例暴漲。（刀駝同時提示「找鮮于無治」，那是後續強化。）
2. **端木草任務（賺第一桶金）**：快活林 端木草 (148,88) 接任 → 東北森林 (197–205,2–7) 找到
   端木林 → 他跟隨你 → 護送回端木草 → **+10,000 兩銀**。
   （之後還可把端木林引去少林，有加成提示。）
3. **香城北的卷軸強盜**：在 (116–120,54–59) 補刀強盜拿「武林秘笈卷軸」
   （**小心同區箭影高人每 2 秒 −2,000 精力**，血薄先別逗留）→ 交給**南宮缺 (73,120)**
   → 任督心脈圖：**本體灌血 +400 萬、馬灌血 +1,400 萬**。前期血量直接起飛。
4. **練功節奏**：先打香城周邊民團／低級怪（每隻 +1 閱歷 +1 兩），在森林區補刀賺木材
   （+2/殺）把佛道醫和刀技逐層學起來。回血術在身上，掛機拖時間血量就會漲——
   舊攻略「先拉高倍數再狂練」的心法照用。

### 中期（16 等起，開金鵬島與各大獎勵）

5. **軒轅獵人 (134,96)**：接任 → 東北角 (234–239,63–71) 殺**鐵豬王**（+2,000 閱歷）→ 回報
   （+1,000 閱歷、上限 −400 反而有利倍數）。
6. **蕭志光（白雲城 227,18）**：接任 → 東邊中段 (232–239,141–158) 殺**靈象** → 回報拿
   **象皮甲（上限 +500）**。
7. **司馬仇 (99,108)**：先到快活林南方大區 (117–152,155–183) 補刀怪物拿**珠寶項飾** →
   賣給司馬仇 → **本體灌血 +200 萬、馬上限 +200**。
8. **搭船去金鵬島**：南港畫舫 (78,234) 需 **16 等 + 2,000 兩**；另一港口 (114,229) 收
   **100,000 精力**（前期血不夠別走這條）。回程 2,000 兩。
9. **渦怪二連**（靈島，漢娜斯一帶）：
   - (16–36,156–165) 補刀渦怪 → **渦怪假牙** → 白雲城**古董收藏家 (236,13)** 賣掉：
     **+50,000 兩、攻擊 +155**（道具會轉成永久標記，照賣不誤）。
   - (2–13,156–170) 補刀**渦怪洛洛普** → **九天玄石** → 金鵬島**術士單玄裝 (93,183)**
     → **九天玄壁：永久 +150 血/秒**（本體與馬各一條迴圈）。這就是舊攻略的「九天任務」，本版在渦怪區。
10. **靈島鳳仙肉**：在靈島 (2–22,171–189) 補刀每殺 **+100 肉 +2 木**，順路存 1,000 肉給神兵用。
11. **迪加（任務學家，12,57）**：
    - 集滿 **3 件**任務道具 → 送科技五項 ＋ **技能點 +200**（上限 −200，有利倍數）。
    - 集滿 **5 件** → **+200,000 兩**，並**解鎖漢娜斯送信任務**。
12. **哥薩克送信**（需迪加 5 件後）：漢娜斯 (25,171) 拿情信 → 香城東**哥薩克騎士 (114,104)**
    → 兩地往返共三趟 → 每趟加上限/攻擊，最後拿**哥薩克軍令**（英雄死亡時獲得一名哥薩克士兵，
    之後解惡夢任務會把這士兵灌到 3,000 萬血——等於一條備用命）。

    → **走到北邊「第四」旗 (186,184)** 才算答對（檔案實證：東=第一、南=第二、西=第三都觸發答錯）。

16. **青書 (86,185)**：100 等（186,125 閱歷）時拜訪 → **保身丹：上限 +6,000×2**。
17. **第 10 層武學「毀樁之舞」**：集滿 12 件任務道具自動獲得——之後在賓周走廊內每次補刀，

### 毀滅之魂（最終戰鑰匙，全隊只有一人能拿）

18. 在**殺人莊東側 (185–207,225–239)** 或**少林東南 (227–239,212–225)** 補刀
    （需在區內停留約 3–4 分鐘後觸發）→「刀客獲得 毀滅之魂」。
19. 帶著它走到**少林魂武僧 (230,207)** → 正式取得：
    - 本體**灌血 +200 萬**、送科技；
    - 生成**飛魂者**（Gaia 靈體，永遠跟著你）；
    - 解鎖**破壞武神**：帶著飛魂者站進 (59–71,189–193)（金鵬島東北法陣），每 20 秒召出

    - 解鎖**斷魂爆破斬**：馬騎刀俠帶飛魂者站在賓周走廊 (55–63,0–15)，每 90 秒召出

    - **飛魂者存在，是賓周巢穴大門開啟的必要條件**。
20. **神兵屠龍刀**：等級夠之後找**天降神兵 (69,217)**，付 **1,000 靈島鳳仙肉** → 取得

    每次使用**損己 6,000 精力**，血夠再開。

## 六、最終決戰（時序與打法）

### 時間機制（先看鐘）

| 遊戲時間 | 事件 |
|---|---|
| 60 分（3600 秒）且飛魂者已存在 | 賓周巢穴柵門 (110–115,1–9) 自動消失（訊息：三小時候即可打開周賓巢穴之門） |
| 83 分（5000 秒） | 警告「魔王每小時加血100萬」 |
| 之後每 50 分（3000 秒） | **魔王黑魔法**：六護法各 +40–70 萬血、賓周 +20 萬、火魂將 +80 萬、巢穴區 +100 萬，且**全圖敵方攻擊 +150** |

→ **不能無限拖**。理想節奏：前 90–120 分鐘做完上面所有任務，第一次黑魔法前後就開打。

### 進場

1. 練到 **66,815 閱歷（約 70 等）**，走到走廊東端**成仔之筆記 (122,3)** 旁 →
   他說「你們先進去，時機一到，我便會去接應你們」→ 走廊圍牆轉為敵對、
   Boss 群回血迴圈啟動（賓周 +397/秒、護法 +150–200/秒——你的 DPS 必須明顯高於這個）。
2. 你走到 x=114 一線時會自動觸發「界線」：P1 版本對 (80–114) 段城牆直接炸 **20 萬血**（一次性）。
   多人時每個玩家各炸一次（6.6 萬–16 萬不等），單人就得自己啃比較多牆。

### 走廊推進（自東向西）

3. **幫眾段 x=90–109**（+2,800 血 +192 攻）→ **弟子段 x=81–89** → **界線牆 x=91（兩面各 131 萬血）、
   x=80（93.6 萬）** → **大弟子段 x=75–80** → **界線牆 x=73（八面各 57.6 萬）**。
   啃牆手段：屠龍刀 +21,000 攻、毀樁之舞（走廊內補刀 → 全廊 4,000 AoE）、
   **斷魂爆破斬**（站 55–63,0–15 每 90 秒 +10,000 攻爆破波）。
4. **六大護法**（各有職業剋制台詞與異常狀態）：雪毒堂 (66,11) 中毒、地裂堂 (57,3) 內傷、
   沙天堂 (48,11) 震懾、冰槍堂 (39,4)、竹劍堂 (28,13)、水刀堂 (21,4)。
   中毒／內傷回走廊東端找**神醫獨孤鐵 (116,4)** 解除。
5. **化功大法警告**：任何英雄一旦**貼近亡魂之堡**（或殺死賓周後），全走廊 (0–114,0–22)
   進入每輪 **−800,000 精力**的持續轟炸——**血量沒有千萬級之前不要靠近城堡**。
   **打掉聚魂塔可立即永久解除化功大法**。

### 斬首與收尾

6. **賓周（14,7，等級 223，3 萬血 +3,400 攻，殺 1 次不算贏）**：接近時他放「天外飛仙／第一快刀」
   ——腳本會在你周圍鋪滿爆炸物（一圈 816），走位拉開再貼身。殺死後：
   - 訊息「殺了我也沒用的！有種進入本幫最大營地！」；
