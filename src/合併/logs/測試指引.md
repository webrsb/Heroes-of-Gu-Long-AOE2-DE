# 測試指引

進遊戲方式：單人 → 劇情（不要用編輯器測試模式）。
照順序驗，每項回報「符合預期」或「異常＋截圖」。

### 驗 s10 自動搬運
本輪無異動，免測。

### 驗 s30 攻擊力修復
改動筆數：590
修復 590 個攻擊力效果。
怎麼測：記下角色目前打怪的單下傷害 → 買一次神兵（任一職業）→ 再打同種怪。
預期：買後單下傷害明顯上升。
異常判讀：買後傷害不變＝修復未生效，回報職業與神兵名。

### 驗 s35 雜項替換
改動筆數：2
const 替換：ref31245 (0.5,4.5)（208→234）；ref21356 (104.5,131.5)（436→2353）
怎麼測：到上列座標看物件。
預期：有外觀、模型正確、小地圖與實景一致。
異常判讀：隱形或問號模型＝新 const 也無外觀，回報座標。

### 驗 s40 雙0血
改動筆數：39
確定性雙0血：歸零本體 0 個 max 操作、3 個開門效果改為直接摧毀。
怎麼測：開場確認亡魂之堡、聚魂塔（守衛塔外觀）、界線牆都站著；
等 15 秒後看 tooltip——三類目標都應「生命 0」；派兵打城堡與塔各 30 秒，持續掉血不回滿。
重點驗開門：清光任一段界線的小兵，該段牆應直接消失（原 +32767 開門已改 Kill）。
異常判讀：誰倒了回報名字；tooltip 有正數回報數字；牆不消失回報「開門失敗」。
