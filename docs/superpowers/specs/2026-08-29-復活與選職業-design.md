# 復活與選職業系統 設計書

2026-08-29 定稿（v5 整併版）。標的：`out/古龍921_合併.aoe2scenario`，一切修改經合併流水線產出，
不動任何來源檔。承接 spike 實證（`src/合併/spikes/`）與使用者逐項裁決。

## 一、需求（使用者裁決彙整）

1. **遊戲內選職業**：六隻展示英雄依使用者佈局站在出發廣場邊（座標見 §五），**全程掛 P8**
   （玩家可點選查看職業數值）、t=0 凍結、頭上 caption＝改名為職業名。點選即選定；
   六職業不可重複、先選先贏、一人一職；任何玩家位可玩任何職業（全矩陣）；
   沒被選走的職業永遠鎖定；少於 6 人自然支援（沒人選的職業家族不啟動）。
2. **每職業 10 條命**（建置參數 `lives`，先以 3 出測試版）：死亡後 **10 秒**於重生區重生；
   升級/任務效果跨命保留；復活無代價。
3. **重生區**：出發廣場方框（聖物碎片旗座四角 77.5,107.5～84.5,114.5）正中央 **(81,111)**，
   所有職業共用；藏兵容器全部疊放於此。
4. **訊息**：非最終死亡＝「{職業名}已受傷，10秒後重生({N})」（N＝累計死亡次數）；
   命盡＝「{職業名}已死亡」。職業名自原「X死」觸發（T3821–3826）訊息萃取。
5. **死亡連動**（馬召收馬、哥8轉裝、魂移、修端木等 54 處）：**每次死亡都觸發**。
   非循環的連動觸發由重生鏈重新啟動，使下次死亡可再觸發；其死亡條件同步展開至各命。
6. 原 12 支「X死」觸發（訊息＋生成 const837 顯示器）退役，由新系統接管。
   const837＝MAP_REVEALER（DE 原生、本來就隱形、功能正常）；防敗功能等價遷移：
   命盡時生成 revealer 給該玩家（照抄原機制）。

## 四、資料模型

- **職業 C**＝原玩家位 1–6 的角色系統（刀/劍/槍/棍/拳/暗）。原本體 ref（0/1/2/502/7/45117）不變。
- **玩家位 S**＝實際玩家 1–6。
- **命 L**＝1..lives。第 1 命＝原本體單位（建置期改掛 P8、移到展示位、t=0 凍結，**ref 不變**
  ——既有 ref 接線對第 1 命零改動；P8 同盟可被玩家點選看數值）。
  第 2..lives 命＝新增同 const 單位（P8 建檔），各駐一個新增隱形容器（1291），容器疊在重生區。
- **配對 (C,S)**＝選角建立；全域唯一 per C、唯一 per S。

## 五、選角系統

展示位座標（使用者 2026-08-29 編輯器擺位萃取）：
P1刀 (78.5,108.5)、P2劍 (80.5,108.5)、P3槍 (82.5,108.5)、P4棍 (83.5,109.5)、
P5拳 (83.5,111.5)（換皮後補位）、P6暗 (83.5,113.5)。全程 P8＋t0 凍結＋改名職業名。

- 每 (C,S) 一支選角觸發：單人=OBJECT_SELECTED；多人版=OBJECT_SELECTED_MULTIPLAYER（帶選取者）。
- 選定 (C,S)：第 1 命轉給 S、解凍 → 啟動 (C,S) 玩家定址家族＋復活鏈第 1 節 →
  停用職業 C 其餘玩家位選角觸發＋玩家位 S 其他職業選角觸發 → 訊息「{S}選擇了{職業名}」。

## 六、接線架構（方案二：欄位中性化＋殘餘矩陣）

本體 ref 引用 1,858 處（六職業計）分四類，全部由建置步驟腳本生成：

1. **效果 ref 清單**（~1,479 處）：追加第 2..lives 命 ref、玩家欄改 -1
   → 六玩家位共用一份；備身在容器中同步吃升級（改名/加攻/加血/打坐）。
2. **條件 ref 欄**（~360 處）：OR 展開至各命 ref，維持單一觸發
   （OR 混排 spike 不過則退回每命複製）。
3. **效果 location_object_reference**（19 處）：無法 OR，逐命複製觸發。
4. **玩家定址觸發**（聊天收件、經貢進貢、資源累積、按玩家過濾區域、為玩家生成；
   精確清單由盤點模組產出）：複製 ×6 玩家位變體，建置時停用，選角時批次啟動 (C,S) 變體。
   跨玩家觸發 16 支逐一裁決寫入 merge_spec。

## 七、復活鏈（每職業一條，per (C,S) 變體）

死亡第 N 次（N < lives）：
1. 死亡偵測：摧毀物件(第 N 命 ref)（建置時停用，前一節啟動）
2. 訊息「{職業名}已受傷，10秒後重生({N})」＋重啟非循環死亡連動觸發
3. 啟動 10 秒計時觸發 → 第 N+1 命駐軍中轉給 S → 移除容器 N+1（於重生區彈出）→ 啟動下一節

死亡第 lives 次：訊息「{職業名}已死亡」＋生成 revealer 給 S（防敗）。

## 九、測試計畫

- 單人（每階段建置後）：選角（含互斥）→ **第 2 命發動職業技能**（接線核心）→ 打坐/升級跨命
  → 死亡連動每死觸發 → 10 秒延遲 → 命盡訊息＋revealer → 未選職業鎖定。陽性對照照鐵律。

- 效能：全量建置後實玩回報。
