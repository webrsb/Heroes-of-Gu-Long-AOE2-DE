# 船夫搭船（DE 重做）設計

日期：2026-08-30　狀態：使用者已逐段核可、三輪 spike 皆已入檔，待書面複審。

## 一、背景

金鵬島線兩座碼頭（東 (110–114, 226–228)、西 (74–81, 233–235)）由 P8 兩艘「畫舫」（運輸船 ref 25003／25004，`船`／`船2` 每 21 秒對開）連接，深水不可步行。

**原作（劍譜5）機制**：`船塢` T3672 永久迴圈在牆位建 Gaia 乾草堆 ×3 當牆；玩家踩外線→報價→走到船夫前→`X船6` 扣費並在牆內水面建一顆該座位的地圖顯示器當「票」；`X草`／`X草2` 偵測「牆內有該座位物件」（票本身就滿足）→ `草草5`／`草草7` 拆牆，`草草6`／`草草8` 計時後關拆牆、重武裝偵測。牆靠「船塢每輪建、草草每輪拆」的時序打架維持通路；玩家走過牆登上盟友（P8）運輸船，船被 task 到對岸**陸地格**時卸貨；抵達者站在牆內同樣觸發拆牆走出；票在踩外線時被 `X船4` 清掉。頭暈（`X頭暈起`→3 分鐘後 `X頭暈` 復原）由東碼頭 `X船6` 在付費時直接啟動。

**基底（無法無天）現況**：作者插入觸發造成 ID 位移，`草草5`～`草草8` 被換成無關觸發——`X草` 現指 T3949/T3950（箭影高人 P5/P6 傷害迴圈，正規開關是 `X當僧`／`X練4`），`X草2` 現指 T3951/T3952（周賓巢穴的橋，正規路徑是狂風犬出現後 3600 秒）。全圖無任何觸發移除那兩道牆。結果：牆永不開、付費照扣、站到牆內就誤開 Boss 橋。使用者體感的「重複被扣錢」＝進不去→走動踩到外線→`X船4` 重武裝整條鏈→再扣一次。

**DE 實測（spike_ferry v1/v2，2026-08-30）**：
- `UNLOAD`（效果 17）能把盟友乘客從 P8 運輸船卸到指定岸格；原作「task 到陸地格」在 DE 對盟友乘客不卸。
- 駐軍中單位計入區域條件，但座標**凍結在登船那格**、不隨船移動（②a PASS／②b FAIL）。
- `TELEPORT_OBJECT`（效果 35）區域選取**一次只搬一隻**；`max_units_affected` 無效；同區域連下 N 個效果可各搬一隻（使用者評「過於暴力」，不採）。
- 駐軍中單位不可被傳送（既有否決事實）。
- 落點格被任何單位壓住時傳送**失敗且無事發生**（spike_ferry3 v3：同落點連傳只到 1 隻）。

## 二、目標與非目標

目標：付費後能可靠登船、渡海、下船、出港；一人一趟一票、隊伍同行；不重複扣費；頭暈只在英雄真正進入登船處時觸發；修掉基底錯線。

非目標：不改票價與等級門檻；不改畫舫班次；不拆牆（牆與 `船塢` 原樣保留）；不處理西海 (9,93) 船夫 2000 兩那條座位 1 獨有路線（另案裁決）。

## 六、待驗與風險

- **待驗（spike_ferry4）**：`船卸` 的實戰形狀——一次性、區域選船、TIMER 8 由派船觸發武裝——登船後派船不會把人卸回、抵岸能卸。過了才建置。
- UNLOAD 會把多名乘客散到船邊各格，可能有人直接落在牆內旗上被瞬間傳出；屬預期，寫進驗收。

- **已驗（spike_ferry3）**：落點被壓住＝傳送失敗、無事發生 → 落點由 `X船清入`／`X船清出` 迴圈用 `TASK_OBJECT` 叫站在上面的單位走開一格；`X船入`／`X船出` 本身是迴圈，失敗那輪單位留在旗格，落點清空後自動重試。（使用者裁決，不採多落點級聯。）
- `X船清入` 只在單位站在落點格那一瞬間下令，玩家在落點格上直接點船會被蓋掉一次，走開後再點即可；牆內清場格在海灘船邊。
- `TIMER` 於觸發被啟動時起算（原作 `1船2`／`草草8` 同用法），3 分鐘窗以此為準。
- 西停船水域含海灘格 (82,y) 只影響 `UNLOAD` 區域選船，不再用於頭暈，無誤判疑慮。
- 多人：六座位各自一套，畫舫共用；兩人同時在牆內互不干擾（各自踩旗各自傳）。

## 七、驗收（單人→劇情，必帶陽性對照）

1. 東碼頭買票 → 提示出現 → 英雄踩牆外旗 → 出現在 (110,226) 且「船暈現象」名牌亮起（對照：寵物先踩旗只傳不暈）。
2. 點畫舫登船 → 船到西岸 → 自動下船在 (81,233) 附近 → 踩 (81,235) → 出現在 (75,234)。
3. 回程買票 2,000 兩 → 同流程回東岸 → 踩 (110,228) → 出現在 (115,231)。
4. 買票後不進去、3 分 10 秒後踩牆外旗 → **不傳**（窗已關，對照：3 分內會傳）。
5. 站在牆內任一格 30 秒 → 周賓橋不變、P5/P6 站 (116,54) 不掉血（錯線已拔）。
6. 全程只被扣一次費。
