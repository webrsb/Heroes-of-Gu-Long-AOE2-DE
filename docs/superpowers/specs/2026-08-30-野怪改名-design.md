# 野怪生成改名（Lv{等級} {真實名}）設計

2026-08-30。目標：野怪生成時把 DE 預設單位名換成任務面板所寫的真實名與等級（如「Lv14 青銅獅」），
提高代入感。本設計經 brainstorming 定案，範圍與資料表由使用者裁決。

## 一、現況與資料源

- 地圖上幾乎沒有預置 P7 野怪；全部由 **61 支生成觸發**動態建立：
  - 啟用中 41 支：常駐補怪（`OWN_FEWER_OBJECTS sp=7 → 移除格 → 建立 → 改血(格) → 改攻(格)`）
    與區域觸發式（玩家進區 → 同上建立流程）；其中 35 支有等級、4 支區間等級、2 支（豬王/豬頭）無等級
  - 停用波次／任務怪（天降神兵系列等）20 支，觸發名為內部代號
- 生成觸發**以真實名命名**（青銅獅、獅頭魔、斬狂…）；等級來自劇情訊息 `hints`
  「入侵者強弱排名」38 行 `Lv{n}{DE單位名}={真實名}`。
- 原作對剛建立單位的定址手法＝**建立點單格區域＋sp=7**（改血/改攻皆如此），實證可用。
- 既有 boss 命名（`賓名`：賓周／六堂護法／神獸火魂將；`1惡2`：惡夢；神兵 KING×5）另一套格式，**不動**。

## 三、注入方式（新步驟 `s373_mobname`）

- 執行順序：s372 之後、s375 之前皆可（無 KR 條件、sp=7 不進矩陣）；取 id `s373`。
- 對 spec 每行：找觸發 → 核對 `name`、所有 `建立(11) sp=7` 效果的 `object_list_unit_id == const`
  → 對每個**帶座標**的建立效果，在觸發尾端追加
  `change_object_name(object_list_unit_id=const, source_player=7,
   area=(x,y,x,y), message=f'Lv{lv} {顯示名}')`。
- 無座標的建立效果（如 T2743 E16 殘留）跳過並記 Change。
- 不新增觸發、無常駐負擔；生成同 tick 內完成改名。

## 四、防呆與測試

- BuildError：觸發不存在／名稱不符／const 不符／該觸發無帶座標建立效果／spec 行重複 tid。
- 單元測試（假件）：追加數量＝帶座標建立數、定址欄位、訊息格式、跳過無座標、四種 BuildError。
- 建置後：s90 對帳、`audit_activation` 違規 0（此步不動啟停圖，僅確認未破壞）。
- 遊戲內：任一補怪區殺怪等補怪，點選看「Lv14 青銅獅」；金獅／銀龍／賓周名稱不變（陽性對照）；
  血條系統（s50 caption）顯示照舊。
