> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把金鵬島線兩座碼頭的「拆牆過門」機制換成 DE 可靠的「買票→3 分鐘售票窗→踩牆外旗傳進→登畫舫→到岸 `UNLOAD`→踩牆內旗傳出」，並拔掉基底接錯的 `X草`／`X草2` 線。

**Architecture:** 全部走 `merge_spec.yaml` 的 `params.trigger_fixes`（既有 s37 施作）：75 支 `trigger_add` 新觸發＋`X船6`／`X船4` 效果編輯＋`X草` 停用。s37 小幅擴充兩點——`effect_add`／`trigger_add` 的啟停效果可用 **觸發名** 指目標（新觸發的 id 在寫 spec 時不存在），`effect_add` 支援 `send_chat`。新觸發帶座位欄位，由 s39 照慣例展開成（職業, 座位）變體；`X船暈` 綁英雄 ref 而非座位，屬職業鍵（shared），由 s39 跨命 OR 展開。spec 區塊由 `tools/gen_ferry_spec.py` 產生後貼入，`tests/test_ferry_spec.py` 守結構。

**Tech Stack:** Python 3.12、AoE2ScenarioParser 0.8.4、PyYAML、pytest（`src/合併` 下執行；`pytest.ini` 預設排除 slow）。

```python
def _resolve_by_name(tm, name, tag):
    """以觸發名找恰一支目標（新觸發的 id 在寫 spec 時不存在，只能以名指）。"""
    hits = [t for t in tm.triggers if (t.name or '') == name]
    if len(hits) != 1:
        raise BuildError(f'缺裁決：{tag} trigger_name「{name}」命中 {len(hits)} 支（須恰 1），請重查')
    return hits[0]
```

```python
def test_ferry_shapes_matrix_relay_shared(f):
    """渡船 spec（2026-08-30）對 s39 的假設：座位欄觸發進矩陣、計時中繼併入後被閉包拉入、
    綁英雄 ref 的頭暈觸發為職業鍵 shared、P8 卸貨不進家族。"""
    FLAG = (112, 227, 112, 227)
    buy = f.trig(name='1船6', conds=[f.cond_area(sp=1, area=(112, 226, 114, 228))],
                 effects=[f.eff_chat(sp=1)])
    enter = f.trig(name='1船入東', conds=[f.cond_area(sp=1, area=FLAG)],
                   effects=[f.eff_teleport(sp=1, area=FLAG, x=110, y=226)], enabled=False, looping=True)

    dizzy = f.trig(name='1船暈東', conds=[f.cond_bring_area(0, area=FLAG)],

    stop = f.trig(name='1船窗止東', conds=[f.cond_timer(180)],
                  effects=[f.eff_deactivate(enter.trigger_id), f.eff_deactivate(dizzy.trigger_id)], enabled=False)
```
